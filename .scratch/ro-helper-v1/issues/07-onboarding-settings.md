# 07: Первый запуск и настройки

**What to build:** При первом запуске пользователь проходит четыре шага, как в макете:
1. Сервер.
2. Организация.
3. Горячая клавиша.
4. Подсказка про режим экрана GTA.

После этого программа запоминает выбор и сразу работает. Кнопка настроек в шапке открывает те же шаги, чтобы всё поменять. Выбранная организация поднимает свои документы в поиске и видна в шапке («Тверской · МВД»).

**Blocked by:** 05 (Поиск по словам), 06 (Оверлей поверх игры)

**Status:** ready-for-agent

- [ ] Шаг «Сервер»: Тверской активен; Арбатский и Кутузовский неактивны с пометкой «скоро»
- [ ] Шаг «Организация»: 13 вариантов из спецификации, включая ОПГ и «Без организации»
- [ ] Шаг «Горячая клавиша»: запись сочетания нажатием; предупреждение, если в сочетании нет Ctrl, Alt или Shift
- [ ] Шаг «Режим экрана»: подсказка про «Оконный без рамки» и итоговая строка с выбором
- [ ] Выбор сохраняется, при следующих запусках первый запуск не показывается
- [ ] Настройки открывают те же шаги с кнопкой «Сохранить». Новая горячая клавиша сразу перерегистрируется
- [ ] Горячая клавиша по умолчанию не пересекается с клавишами GTA V и Russia Online. Выбор и причина записаны в тикете
- [ ] Связи «организация → документы» хранятся в данных. Выбранная организация поднимает свои документы в поиске
- [ ] Тесты интерфейса: весь поток первого запуска и повторный вход через настройки с заглушкой адаптера
