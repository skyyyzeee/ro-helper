# 07: Первый запуск и настройки

**What to build:** При первом запуске пользователь проходит четыре шага, как в макете:
1. Сервер.
2. Организация.
3. Горячая клавиша.
4. Подсказка про режим экрана GTA.

После этого программа запоминает выбор и сразу работает. Кнопка настроек в шапке открывает те же шаги, чтобы всё поменять. Выбранная организация поднимает свои документы в поиске и видна в шапке («Тверской · МВД»).

**Blocked by:** 05 (Поиск по словам), 06 (Оверлей поверх игры)

## Comments

2026-09-10 — сделано.

**Горячая клавиша по умолчанию — Alt + Q.**
- Пользователь проверил её в игре на Тверском в задаче 06: работает и ни с чем не пересекается.
- В стандартной раскладке GTA V одна Q — «укрытие», а сочетание Alt + Q не занято. Глобальная клавиша срабатывает только вместе с Alt, поэтому одиночная Q доходит до игры как обычно.
- Публичного списка клавиш Russia Online нет ни на вики (russiaonline.wiki), ни в поиске, так что решение основано на проверке в игре.

**Данные:**
- `data/tverskoi/organizations.json`: 13 организаций с документами из таблицы спецификации.
- В `servers.ts` перечислены все документы Тверского, в том числе ещё не импортированные (id вида `fz6`, `ch-mvd`, `rules-crime`), чтобы организации могли на них ссылаться.
- Импортёр проверяет, что каждая организация ссылается только на известные документы. Буст документов, которых ещё нет в пакете, просто ничего не делает, пока они не появятся (задачи 14–15).

**Как устроено:**
- **Профиль** (`profile` в настройках платформы): сервер, организация, горячая клавиша. Пока профиля нет, вместо поиска показываются четыре шага первого запуска, по макету. Серверы, кроме Тверского, — «скоро» («скоро · для новичков» у Кутузовского).
- **Запись горячей клавиши:**
  - берётся физическая клавиша (`code`), поэтому русская раскладка не мешает: Alt + Й записывается как Alt + Q;
  - подходят буквы, цифры, F1–F24, пробел, Ё, Ins/Del/Home/End/PgUp/PgDn; Esc отменяет запись;
  - **пока идёт запись, текущая глобальная клавиша снимается**, иначе Windows перехватывала бы то же сочетание и оверлей просто скрывался бы;
  - если `code` пустой (так бывает у синтетических событий, например у инструмента автоматизации), клавиша распознаётся по `key`: латинская буква, цифра, F-клавиша.
- **Настройки** (шестерёнка): строка «Тверской · МВД · Ctrl + Shift + L» с кнопкой «Изменить» открывает те же шаги в режиме настроек («Сохранить», «Отмена», Esc — выйти без сохранения). После сохранения горячая клавиша перерегистрируется сразу. Там же прозрачность и сброс положения окна из задачи 06.
- **Поиск:** документы выбранной организации получают +5 (ГИБДД: «оскорбление» → сначала КоАП 5.4, МВД → сначала УК 104). В шапке — «Тверской · МВД», для «Без организации» — просто «Тверской».

**Тесты:** 78 зелёных.
- Весь первый запуск с записью клавиш.
- Отмена записи через Esc, «Назад», пропуск первого запуска при сохранённом профиле.
- Вход через настройки с сохранением и перерегистрацией клавиши, выход без сохранения.
- Влияние организации на порядок результатов.
- Разбор сочетаний, включая русскую раскладку и события без `code`.
- 13 организаций в пакете.

Старые тесты интерфейса переведены на общий помощник `src/test/renderApp.tsx`, который сохраняет профиль и ждёт загрузки.
