# 03: Сквозной путь: статья УК по номеру

**What to build:** Пользователь набирает `65` или `ук 65` и сразу видит статью УК. В строке результата — бейдж документа, номер, название, подследственность `[Р/Ф]`, звёзды и наказание. По клику открывается текст статьи. Данные настоящие: они разобраны из сохранённого текста темы УК Тверского. Это первый проход через все слои: исходник → разборщик → пакет данных → поиск ядра → интерфейс.

**Blocked by:** 02 (Каркас приложения)

**Status:** ready-for-agent

- [ ] Исходный текст первого сообщения темы УК (forum.russia.online, тема 1176) сохранён в проекте вместе с метаданными: ссылка, дата правки первого сообщения, дата снимка. Текст получен через браузер пользователя (Claude in Chrome) или вставлен пользователем. Анти-DDoS защиту форума не обходим
- [ ] Модель данных законов описана по спецификации: сервер, документ, глава, статья, часть, наказание, пакет данных сервера
- [ ] Разборщик УК понимает:
  - [ ] разделы, главы и статьи, включая номера вида `x.1`
  - [ ] строки частей с тегами `[Р/Ф]` и `[★★★]`
  - [ ] наказания: штраф «до N» и «от N до M», лишение свободы; «либо» разбирается как альтернатива
  - [ ] примечания и пояснения
- [ ] Статьи, которые разборщик не смог разобрать, перечисляются в отчёте, а не пропадают молча

- [ ] Результаты в оверлее выглядят как в макете. Клик открывает простой просмотр статьи (полный экран статьи — в задаче 10)
