# 03: Сквозной путь: статья УК по номеру

**What to build:** Пользователь набирает `65` или `ук 65` и сразу видит статью УК. В строке результата — бейдж документа, номер, название, подследственность `[Р/Ф]`, звёзды и наказание. По клику открывается текст статьи. Данные настоящие: они разобраны из сохранённого текста темы УК Тверского. Это первый проход через все слои: исходник → разборщик → пакет данных → поиск ядра → интерфейс.

**Что есть в УК на самом деле (дополнения к спецификации):**
- Помимо `Р` и `Ф` есть подследственность `В` (военная): `[В]`, `[Р/Ф/В]`. Добавлена в модель.
- Звёзды бывают диапазоном: `[от ★ до ★★★★★]` (ст. 100.1). Срок по этой статье зависит от уровня розыска (1★ = 10 мес) и хранится как отдельный вид наказания.
- Три формы штрафа: «до N», «от N до M», фиксированная сумма (ст. 55 ч. 2, ст. 74 ч. 1).
- Бывает штраф без звёзд (ст. 60 ч. 1), звёзды без подследственности (ст. 51 ч. 2), наказание без слова «наказывается» (ст. 112), номер части после метки (ст. 113).
- У военных статей обязательное дополнение «лишение воинского звания».
- В особенной части части не пронумерованы. Номер ставится по порядку (ч. 1, ч. 2…), так же на них ссылается сам текст («частями первой или второй»).
- Подследственность части без метки не наследуется от первой части. В тексте она не указана, поэтому остаётся пустой.
- Подпись в конце («Одобрен Государственной Думой…», «Подписан…») распознаётся отдельно и в статьи не попадает.
- **Для задачи 08:** категории тяжести (для залога) определены в ст. 11 через максимальный срок: небольшая ≤ 20 мес, средняя ≤ 30 (неосторожные ≤ 35), тяжкие ≤ 40 (≤ 45), особо тяжкие > 40. Их можно вычислять из сроков, отдельной разметки не нужно.

**Как устроено:**
- `npm run import` собирает пакет и печатает всё, что не разобрано. Если что-то не разобрано, команда завершается с ошибкой.
- Разборщик строгий: если после наказания остался непонятый хвост, это попадает в отчёт. На этом поймана ошибка: `\b` в регулярных выражениях JS не работает с кириллицей, и «либо» не разделялось.
- Эталон — вшитый пакет: тест пересобирает его из исходников и сравнивает целиком, так что разборщик и данные не могут разойтись.
- Версия пакета — дата самой свежей правки закона в нём (2026-09-06).
- Поиск: номер, псевдоним документа, «ст.»; точный номер → подстатьи (65 → 65.1) → начинающиеся с номера (6 → 60…). Слова — в задаче 05.

**Доделано при проверке по спецификации:** у сервера есть статус (`active` / `soon`), у документа — вид (`penal-code` / `law` / `charter` / `rules`) рядом с категорией для меню. Профиль правил калькулятора, организации и словарь синонимов остаются в своих задачах (08, 07, 05).
