# 09: КоАП в калькуляторе и копирование обвинения

**What to build:** Статьи КоАП в калькуляторе считаются отдельным блоком: у каждой своя сумма, суммы складываются, есть переключатель «гражданин / должностное лицо». Одна кнопка «Скопировать» (или Ctrl+C) даёт строку с перечнем статей для рапорта, рации или чата. Весь путь «горячая клавиша → номер → Enter → Ctrl+C → Esc» проходится без мыши.

**Blocked by:** 04 (КоАП и ПДД + ручные правки), 08 (Калькулятор УК)

**Status:** ready-for-agent

- [ ] У каждой статьи КоАП поле суммы (по умолчанию предел) и проверка по пределу для выбранного субъекта, с сообщением, если сумма больше
- [ ] Переключатель «гражданин / должностное лицо» для блока КоАП
- [ ] «Итого КоАП» — сумма (ст. 4.5) с потолками штрафа (ст. 3.5) и ареста (ст. 3.6). Как применяются потолки (на одно нарушение или на сумму) — сверить с текстом КоАП и записать в тикете
- [ ] Строка обвинения содержит только статьи, сгруппированные по документам, по возрастанию номера, без сроков, звёзд и «РО»: `ст. 65, 88 УК; ст. 8.6 ч. 1 КоАП`
- [ ] Кнопка «Скопировать» и Ctrl+C (когда в поиске нет выделенного текста) копируют строку через адаптер; появляется подтверждение «Скопировано»
- [ ] Тесты ядра: сумма, пределы для обоих субъектов, формат строки
- [ ] Тест интерфейса: путь с клавиатуры `65` → Enter → Ctrl+C копирует ожидаемую строку
