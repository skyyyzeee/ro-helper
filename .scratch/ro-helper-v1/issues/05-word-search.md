# 05: Поиск по словам

**What to build:** Поиск находит статьи не только по номеру, но и по словам, как их говорят игроки. `кражу` находит «Кража», `тонировка` — статью о тонированных стёклах, опечатка не ломает результат. В результатах сначала совпадения по номеру, потом по названию, потом по тексту; документы организации пользователя выше остальных. Стрелки ↑↓ перемещают выделение.

**Blocked by:** 03 (Сквозной путь: статья УК по номеру)

## Comments

2026-09-10 — сделано.

**Тонировки нет.** В УК, КоАП и ПДД Тверского нет статьи о тонированных стёклах: нет ни «тонир», ни «светопропускаемости». Пример в задаче пришёл из макета, где статьи были выдуманными. Словарь синонимов (`data/tverskoi/synonyms.json`) собран из слов, у которых точно есть статья: «ствол», «пушка» → огнестрельное оружие; «наркота» → наркотические средства; «теракт» → террористический акт; «мат» → нецензурная брань; «пьяный» → опьянение; «парковка» → стоянка и т.д. Отдельный тест требует, чтобы каждый синоним из словаря что-то находил. Когда в законах появится тонировка, её достаточно дописать в словарь.

**Как устроено:**
- **Стемминг:** стандартный алгоритм Snowball для русского (`src/core/stem.ts`), без внешних библиотек.
- **Индекс:** строится один раз на пакет при первом поиске. У статей с несколькими наказанными частями каждая часть ищется отдельно («кража группой» → только ст. 65 ч. 2).
- **Как может совпасть слово:**
  - точная основа (×1);
  - начало набираемого последнего слова («самовольн» → ст. 109) (×0,6);
  - синоним (25 очков, если фраза целиком в названии, иначе 20);
  - опечатка (×0,5), но только для слов, которых в законах нет вообще (иначе «кража» цеплялась за «по правому краю» в ПДД), с совпадающей первой буквой, 1 правка для слов от 5 букв, 2 — от 8.
- **Очки:** номер 1000 (номер с подстатьями и частями работает как раньше и сочетается со словами: «8.6 скорость»); название 30, синоним 25/20, текст 10; документ организации +5; кодекс с наказаниями +3. Совпасть должны все слова запроса.
- **Скорость:** на корпусе в 1,7 млн символов (6 копий нынешнего пакета) индекс строится за ~55 мс (после кэширования основ; без кэша было ~635 мс), нажатие клавиши в среднем ~0,5 мс. Тест требует меньше 16 мс на нажатие.
- **↑↓ в строке поиска:** первая строка выделена сразу, стрелки двигают выделение, выделенная строка прокручивается в видимую зону, новый запрос возвращает выделение наверх. Enter и → — в задачах 08 и 10.

**Итог:** 60 тестов зелёные, проверка типов и сборка чистые. В браузере проверено: «превышене скорости» (с опечаткой) → три части КоАП 8.6, стрелки перемещают выделение.
