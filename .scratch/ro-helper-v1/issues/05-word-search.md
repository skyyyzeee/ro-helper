# 05: Поиск по словам

**What to build:** Поиск находит статьи не только по номеру, но и по словам, как их говорят игроки. `кражу` находит «Кража», `тонировка` — статью о тонированных стёклах, опечатка не ломает результат. В результатах сначала совпадения по номеру, потом по названию, потом по тексту; документы организации пользователя выше остальных. Стрелки ↑↓ перемещают выделение.

**Blocked by:** 03 (Сквозной путь: статья УК по номеру)

**Status:** ready-for-agent

- [ ] Стемминг русского языка (кража / кражу / кражи), «ё» приравнена к «е»
- [ ] Словарь синонимов хранится в данных, а не в коде. `тонировка` находит статью о тонированных стёклах
- [ ] Опечатка в 1–2 символа в слове прощается
- [ ] Порядок: номер > название > синоним > текст. Выше поднимаются документы выбранной организации и основные кодексы (организация пока параметр поиска, её выбор — в задаче 07)
- [ ] Поиск отвечает мгновенно на каждое нажатие клавиши на всех загруженных документах, с запасом на полный корпус Тверского (~1,3 млн символов)
- [ ] ↑↓ перемещают выделение по результатам
- [ ] Тесты ядра на настоящих данных: форма слова, синоним, опечатка, порядок результатов, влияние организации на порядок
