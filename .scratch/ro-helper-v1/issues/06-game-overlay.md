# 06: Оверлей поверх игры

**What to build:** Программа запускается как настоящее приложение Windows. В GTA (режим «оконный без рамки») пользователь нажимает горячую клавишу, и поверх игры появляется оверлей с курсором в строке поиска. Повторное нажатие или Esc скрывает его, и управление сразу возвращается игре. Окно можно двигать и растягивать, программа запоминает, где оно было.

**Blocked by:** 01 (Инструменты для Tauri), 02 (Каркас приложения)

**Status:** ready-for-human — всё сделано, осталась ручная проверка в игре

- [x] Приложение собирается на Tauri 2 с настоящей реализацией платформенного адаптера
- [x] Глобальная горячая клавиша срабатывает, когда фокус у игры. Пока используется временное сочетание, выбор клавиши — в задаче 07 *(срабатывание в игре — в ручной проверке)*
- [x] Окно без рамки, поверх всех окон, со стеклянным фоном; видно поверх GTA в режиме «оконный без рамки» *(поверх GTA — в ручной проверке)*
- [x] При открытии курсор в строке поиска, при скрытии фокус возвращается игре
- [x] Окно можно двигать и менять его размер. Положение и размер запоминаются, по умолчанию оверлей справа на ~⅓ экрана. В настройках есть сброс положения
- [x] Прозрачность фона регулируется
- [x] Esc работает по слоям: закрыть статью → очистить поиск → скрыть оверлей
- [x] Размытие игры за окном: проверить системный эффект Windows (Acrylic) на лаги при перетаскивании. Если лагает — полупрозрачный фон без размытия. Решение записать комментарием в этом тикете
- [ ] Ручной чек-лист в игре пройден пользователем, результат записан в тикете: горячая клавиша при фокусе игры, окно поверх игры, возврат фокуса, сохранение положения (в том числе на втором мониторе), нагрузка на FPS

## Comments

2026-09-10 — сделано всё, кроме проверки в игре.

**Как устроено:**
- **Окно:** Tauri 2, прозрачное, без рамки, поверх всех окон, без кнопки в панели задач. При старте скрыто, пока не восстановлено положение, потом показывается.
- **Трей:** иконка в трее с «Показать / скрыть» и «Выход»; клик по иконке переключает оверлей. Без трея окно без рамки было бы нечем закрыть.
- **Один экземпляр:** повторный запуск программы не создаёт второй оверлей, а переключает уже запущенный.
- **Горячая клавиша:** временная **Alt + Q** (постоянную выбираем в задаче 07). Регистрируется через плагин global-shortcut. Вызовы идут в очередь, иначе React в режиме разработки успевал зарегистрировать клавишу дважды («HotKey already registered»).
- **Фокус:**
  - перед показом нативная команда запоминает окно, у которого был фокус (игру), после скрытия возвращает фокус ему (`SetForegroundWindow`);
  - при показе курсор ставится в строку поиска;
  - после клика по результату или «← Результаты» курсор тоже возвращается в поиск, иначе Esc и набор текста уходили «в никуда»: это поймал тест.
- **Положение и размер:**
  - по умолчанию правая треть рабочей области экрана, ширина от 480 до 760 px (с учётом масштаба), высота на весь экран за вычетом отступов 24 px;
  - после перемещения или изменения размера положение сохраняется (`settings.json` в папке данных приложения);
  - сохранённое положение восстанавливается, только если окно всё ещё попадает на какой-нибудь монитор (на случай отключённого второго монитора);
  - «Сбросить положение окна» в настройках возвращает положение по умолчанию.
- **Перемещение и размер без рамки:** окно перетаскивается за шапку, размер меняется за невидимые края и углы.
- **Настройки (шестерёнка):** ползунок «Прозрачность фона» (5–65 %, по умолчанию 38 % — как в макете) сохраняется; сброс положения; текущая горячая клавиша. Сервер, организация и выбор клавиши — задача 07.
- **Esc по слоям:** настройки → статья → текст поиска → скрыть оверлей. Обработчик стоит на окне, а не на элементе.

**Решение по размытию (Acrylic):** системный эффект не включаем, стекло полупрозрачное без размытия.
- Документация Tauri прямо предупреждает: у Acrylic плохая производительность при изменении размера и перетаскивании окна в Windows 10 v1903+ и Windows 11 build 22000.
- Размыть игру за окном средствами CSS нельзя: `backdrop-filter` размывает только содержимое самой страницы, а за прозрачным окном — чужое окно.
- Читаемость держат тёмный фон с регулируемой прозрачностью и белый текст с тенью.
- Если в игре фон будет мешать, прозрачность можно убавить в настройках. Если захочется попробовать Acrylic, это одна строка в конфиге окна.

**Проверено на этом компьютере без игры** (Windows API из PowerShell с учётом DPI):
- окно видимо, поверх всех окон, с фокусом;
- стоит в `1776,24`, размер `760×1344` при рабочей области `2560×1392` — ровно правая треть с отступами;
- положение записано в настройки.

Горячую клавишу эмулировать не стал: к моменту проверки фокус был в другом окне, а слать нажатия в чужое окно нельзя.

**Автотесты:** 66 зелёных, из них 6 новых на окно (с заглушкой платформы): горячая клавиша скрывает и показывает с курсором в поиске; Esc по слоям; прозрачность меняется, сохраняется и восстанавливается при старте; сброс положения и края для изменения размера есть в приложении и отсутствуют в браузере. Проверка типов, сборка фронтенда и Rust чистые.

**Чек-лист для проверки в игре** (запуск: `npm run tauri dev`, при первом старте Rust собирается 1–2 минуты):
1. GTA в режиме «Оконный без рамки», фокус в игре → **Alt + Q** → оверлей появился поверх игры, курсор в поиске, можно печатать.
2. Ещё раз **Alt + Q** (или Esc на пустом поиске) → оверлей скрылся, управление сразу у игры: мышь крутит камеру, WASD двигает персонажа.
3. Перетащить оверлей за шапку, потянуть за край → закрыть программу через трей («Выход») → запустить снова → окно на том же месте. Если есть второй монитор — то же на нём.
4. Настройки → «Сбросить положение окна» → вернулось вправо.
5. FPS в игре с открытым оверлеем и без него (оверлейный счётчик FPS в Steam/NVIDIA/игре) — заметна ли разница.
6. Не пересекается ли Alt + Q с чем-то в Russia Online.
