# 06: Оверлей поверх игры

**What to build:** Программа запускается как настоящее приложение Windows. В GTA (режим «оконный без рамки») пользователь нажимает горячую клавишу, и поверх игры появляется оверлей с курсором в строке поиска. Повторное нажатие или Esc скрывает его, и управление сразу возвращается игре. Окно можно двигать и растягивать, программа запоминает, где оно было.

**Blocked by:** 01 (Инструменты для Tauri), 02 (Каркас приложения)

**Status:** ready-for-agent

- [ ] Приложение собирается на Tauri 2 с настоящей реализацией платформенного адаптера
- [ ] Глобальная горячая клавиша срабатывает, когда фокус у игры. Пока используется временное сочетание, выбор клавиши — в задаче 07
- [ ] Окно без рамки, поверх всех окон, со стеклянным фоном; видно поверх GTA в режиме «оконный без рамки»
- [ ] При открытии курсор в строке поиска, при скрытии фокус возвращается игре
- [ ] Окно можно двигать и менять его размер. Положение и размер запоминаются, по умолчанию оверлей справа на ~⅓ экрана. В настройках есть сброс положения
- [ ] Прозрачность фона регулируется
- [ ] Esc работает по слоям: закрыть статью → очистить поиск → скрыть оверлей
- [ ] Размытие игры за окном: проверить системный эффект Windows (Acrylic) на лаги при перетаскивании. Если лагает — полупрозрачный фон без размытия. Решение записать комментарием в этом тикете
- [ ] Ручной чек-лист в игре пройден пользователем, результат записан в тикете: горячая клавиша при фокусе игры, окно поверх игры, возврат фокуса, сохранение положения (в том числе на втором мониторе), нагрузка на FPS
