# 08: Калькулятор УК

**What to build:** Полицейский добавляет статьи УК в калькулятор клавишей Enter из результатов или кнопкой «+». Как только добавлена первая статья, сбоку от списка к центру экрана выдвигается панель калькулятора; когда список пуст, она исчезает. В режиме «КПЗ» калькулятор показывает итоговый срок по закону (поглощение), объясняет его ссылками на статьи, подсказывает, сколько звёзд выдать, считает залог и предупреждает о федеральной подследственности. В режиме «Штраф» полицейский вводит сумму, а калькулятор проверяет её по пределу.

**Blocked by:** 03 (Сквозной путь: статья УК по номеру)

**Status:** ready-for-agent

- [ ] Enter в результатах и кнопка «+» добавляют и убирают статью. Добавленная статья отмечена в результатах
- [ ] Панель выдвигается в сторону центра экрана при первой статье и исчезает при пустом списке. Кнопка «Очистить», удаление статьи крестиком
- [ ] Переключатель «КПЗ / Штраф» на всё задержание. «Штраф» недоступен, если у какой-то статьи УК нет штрафа; подсказка называет эти статьи
- [ ] КПЗ: итог — самое строгое наказание (УК ст. 41 ч. 2). Поглощённые статьи зачёркнуты, пояснение говорит, какая статья поглотила какие
- [ ] Ст. 104 добавляется поверх самого строгого наказания один раз (ст. 41 ч. 4)
- [ ] У статьи есть переключатели «покушение» (¾) и «приготовление» (½) по ст. 45
- [ ] Итоговый срок не больше 100 месяцев (ст. 39 ч. 2), с пояснением, если потолок сработал
- [ ] Звёзды к выдаче: 1★ = 10 мес (ст. 100)
- [ ] Залог по самому тяжкому преступлению (ст. 50.1). Категории тяжести берутся из текста УК; как их определить в данных — решить и записать в тикете
- [ ] Штраф: сумму вводит полицейский; калькулятор проверяет её по пределу самой строгой статьи (с учётом ст. 104)
- [ ] Для статей с подследственностью `[Ф]` показано предупреждение «федеральная подследственность, дело ФСБ»
- [ ] Правила (поглощение, 104, ст. 45, потолок, звёзды, залог) — параметры профиля сервера, а не константы в коде калькулятора
- [ ] Тесты ядра на настоящих статьях УК — по каждому правилу отдельно и в сочетаниях
- [ ] Тест интерфейса: панель появляется и исчезает; «Штраф» недоступен с подсказкой
