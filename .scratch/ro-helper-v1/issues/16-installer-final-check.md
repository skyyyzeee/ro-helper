# 16: Установщик и финальная проверка в игре

**What to build:** Игрок скачивает установщик, ставит РО Хелпер и с первого запуска пользуется им в игре. Перед публичным релизом вся программа проходит ручной чек-лист в игре, а для администрации проекта подготовлено короткое сообщение.

**Blocked by:** 07 (Первый запуск и настройки), 09 (КоАП в калькуляторе и копирование обвинения), 11 (Меню документов), 12 (Закреплённая карточка), 13 («Что изменилось»), 15 (Уставы организаций и правила проекта)

**Status:** ready-for-human

- [ ] Установщик для Windows 10/11 без цифровой подписи. Установка и первый запуск работают на чистой учётной записи Windows
- [ ] Программа работает офлайн на вшитом пакете данных
- [ ] Полный ручной чек-лист в игре пройден пользователем, результат записан в тикете:
  - [ ] горячая клавиша срабатывает, когда фокус у игры
  - [ ] оверлей поверх игры, фокус возвращается игре
  - [ ] клики проходят сквозь закреплённую карточку
  - [ ] положение окон сохраняется, в том числе на втором мониторе
  - [ ] нагрузка на FPS
- [ ] Подготовлен текст короткого сообщения администрации Russia Online о программе (отправляет пользователь)

## Сделано

- Установщик NSIS на русском, только для текущего пользователя (без прав администратора и UAC), ярлык в «Пуске», без автозапуска. Отображаемое имя «РО Хелпер», exe — `ro-helper.exe`, файл установщика в релизе — `RO-Helper_<версия>_x64-setup.exe`.
- Своя иконка (`design/icon/icon.svg` → `src-tauri/icons`).
- Версия 1.0.0; единственный источник — `package.json` (`tauri.conf.json` ссылается на него, настройки показывают её же).
- Автообновление: плагин updater, `latest.json` из последнего опубликованного релиза GitHub, обновления подписаны ключом проекта. Проверка при запуске и раз в 6 часов; плашка «Доступна версия X — Что нового / Обновить / Позже»; «Позже» — до следующей версии; в настройках «Проверить обновления». Установка в режиме passive: программа закрывается, установщик ставит новую версию и запускает её.
- В настройках: «РО Хелпер 1.0.0 · автор skyze», ссылки на GitHub и Discord.
- GitHub Actions: `release.yml` (тег `v*` → тесты → сборка → подпись → черновик релиза с `latest.json`), `ci.yml` (типы и тесты на push/PR).
- README со скриншотами (`docs/screenshots`, снимаются headless-Edge из превью), LICENSE (MIT, тексты законов — отдельно).
- Офлайн: законы вшиты, без сети не работает только проверка обновлений (молча).
- Тесты: `src/ui/Updates.test.tsx`.

## Осталось (пользователь)

1. Ключ подписи создан (`%USERPROFILE%\.tauri\ro-helper.key`), открытый ключ — в `plugins.updater.pubkey`. Осталось: закрытый ключ (содержимое файла) и пароль — в секреты GitHub `TAURI_SIGNING_PRIVATE_KEY`, `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`; сам файл сохранить в надёжном месте: без него установленные копии не обновятся.
2. Установить на чистой учётной записи Windows и пройти чек-лист в игре:

| Проверка | Результат |
| --- | --- |
| Установщик запускается (SmartScreen → «Выполнить в любом случае»), ставится без UAC | |
| Первый запуск: сервер, организация, горячая клавиша | |
| Горячая клавиша срабатывает, когда фокус у игры | |
| Оверлей поверх игры («Оконный без рамки»), по Esc/горячей клавише фокус возвращается игре | |
| Клики проходят сквозь закреплённую карточку | |
| Положение окон сохраняется, в том числе на втором мониторе | |
| Нагрузка на FPS: с открытым оверлеем, со скрытым, с карточкой | |
| Без интернета всё работает | |
| Обновление: релиз 1.0.1 → программа 1.0.0 предлагает обновиться и обновляется | |

Это окно поверх игры по горячей клавише, в котором собраны законы, уставы организаций и правила проекта с поиском, а также калькулятор срока и штрафа по УК и КоАП (с поглощением, потолками и залогом) и копирование обвинения одной кнопкой.
