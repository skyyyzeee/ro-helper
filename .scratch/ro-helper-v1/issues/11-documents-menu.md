# 11: Меню документов

**What to build:** Кнопка в шапке оверлея выдвигает боковое меню со всеми документами сервера, как в макете:
- фильтр по названию;
- теги «Все / Кодексы / ФКЗ / ФЗ / Москва / Уставы / Правила»;
- группы с бейджами и числом статей, документы организации пользователя первой группой.

Клик по документу ограничивает поиск этим документом и позволяет листать его по главам.

**Blocked by:** 04 (КоАП и ПДД + ручные правки), 07 (Первый запуск и настройки)

**Status:** ready-for-agent

- [ ] Меню выдвигается поверх левой части оверлея; затемнение или крестик его закрывают; Esc закрывает меню первым
- [ ] Фильтр по названию и бейджу документа; теги по видам документов
- [ ] Первая группа — «<Организация> · ваша организация», дальше группы по видам. У каждого документа бейдж категории, название и число статей
- [ ] Клик по документу: в строке поиска появляется метка документа (сбрасывается крестиком), поиск идёт только по нему, при пустом запросе видны его статьи
- [ ] Просмотр документа по главам: список глав, внутри статьи
- [ ] Тесты интерфейса: фильтр, теги, группа организации, ограничение поиска документом
