# 11: Меню документов

**What to build:** Кнопка в шапке оверлея выдвигает боковое меню со всеми документами сервера, как в макете:
- фильтр по названию;
- теги «Все / Кодексы / ФКЗ / ФЗ / Москва / Уставы / Правила»;
- группы с бейджами и числом статей, документы организации пользователя первой группой.

Клик по документу ограничивает поиск этим документом и позволяет листать его по главам.

**Blocked by:** 04 (КоАП и ПДД + ручные правки), 07 (Первый запуск и настройки)

**Status:** done

- [x] Фильтр по названию и бейджу документа; теги по видам документов
- [x] Первая группа — «<Организация> · ваша организация», дальше группы по видам. У каждого документа бейдж категории, название и число статей
- [x] Клик по документу: в строке поиска появляется метка документа (сбрасывается крестиком), поиск идёт только по нему, при пустом запросе видны его статьи

## Comments

2026-09-11 — сделано. Решения приняты с пользователем перед реализацией.

**В меню только документы, которые есть в пакете.** Сейчас это УК, КоАП и ПДД; остальные 41 документ Тверского появятся с задачей 14, и меню вырастет само, без правок кода. Теги показываются только для видов, которые есть в пакете (сейчас «Все / Кодексы»), чтобы ни один не вёл в пустой список. Группа организации — её документы из пакета в её порядке (у ГИБДД — ПДД и КоАП, у МВД пока группы нет); с фильтром или тегом группа организации не показывается.

**Оглавление целиком.** Выбран документ, запрос пуст — заголовки глав (прилипают сверху при прокрутке), под ними строки статей, как в поиске: по частям с наказанием, с «+», Enter в калькулятор, → открывает статью, «← Оглавление» возвращает. У статей без наказания вторая строка — начало текста, а не повтор названия главы.

**Метка и Esc.** Метка `УК ×` в строке поиска, placeholder «Поиск: Уголовный кодекс». Esc по слоям: настройки → меню → статья → текст запроса → метка → скрыть оверлей. Backspace в пустой строке снимает метку.

**Явный псевдоним сильнее метки:** выбран КоАП, запрос `ук 65` — ищем в УК. В ядре — опция `document` у `searchArticles` и `documentContents` для оглавления.

**Клавиатура в меню:** курсор сразу в фильтре, ↑↓ и Enter выбирают документ, Esc закрывает и возвращает курсор в поиск.

**Одно выделение, а не два** (замечание пользователя: заливка оставалась на первой строке, а обводка переезжала на выбранный документ — выглядело как зависание). Курсор клавиатуры при открытии меню стоит на текущем документе, мышь переносит его на строку под собой, после смены фильтра или тега он возвращается на текущий документ, если тот виден. Документ, который есть в двух группах (организации и по виду), выделяется только в первой.

**Тесты:** 138 зелёных (было 126): 2 теста ядра (ограничение документом, оглавление) и 10 тестов интерфейса (`DocumentsMenu.test.tsx`) — список и счётчики, группа организации и её отсутствие, фильтр, закрытие тремя способами, выбор с клавиатуры, оглавление с ↑↓ и →, поиск внутри документа и псевдоним, Esc по слоям, Backspace и крестик метки.

**Проверено в браузере** с организацией ГИБДД: группа «ГИБДД · ваша организация», выбор УК с клавиатуры, оглавление с прилипающими главами до гл. 14 (ст. 65–67 по частям с наказаниями). В игре (Tauri) не проверялось.
