# 13: «Что изменилось»

**What to build:** Когда законы на форуме меняются и разработчик обновляет данные, импортёр показывает, что изменилось, до сохранения. После обновления программы пользователь один раз видит экран «Что изменилось»: изменённые, добавленные и удалённые статьи по документам с датами. Изменённую статью можно открыть в формате «было → стало», а в результатах поиска недавно изменённые статьи отмечены.

**Blocked by:** 04 (КоАП и ПДД + ручные правки), 10 (Статья целиком, избранное и недавние)

**Status:** done

- [x] Ядро сравнивает две версии пакета: добавленные, удалённые и изменённые статьи, у изменённых — текст «было → стало»
- [x] Импортёр перед сохранением показывает отчёт об изменениях относительно прошлой версии
- [x] Источник данных хранит последнюю версию, которую видел пользователь. После обновления показывается экран «Что изменилось»

- [x] Тесты ядра: добавленная, удалённая и изменённая статья

## Сделано

- Версия пакета — время последней правки законов на форуме (ISO), `changes` — журнал обновлений за 90 дней (`data/tverskoi/changelog.json`).
- Ядро (`src/core/changes.ts`): `diffPacks` — добавленные, удалённые и изменённые статьи по документам (документ целиком — одна запись); `diffWords` — пословное сравнение для «было → стало»; `changesSince`, `recentChanges`, `changedArticles`.
- Импортёр печатает отчёт: «Изменения законов» (у документа изменилась дата правки на форуме — идут в журнал) и «Изменения разборщика» (только для разработчика). `npm run import -- --check` — отчёт без сохранения.
- Настройка `laws.seen:<сервер>` — последняя увиденная версия. Первый запуск ничего не показывает; после обновления один раз открывается «Что изменилось — С прошлого обновления».
- Экран «Что изменилось»: правки по датам и документам, метки Изменено (жёлтая) / Добавлено (зелёная) / Удалено (красная). Изменённая или удалённая статья открывается как «было → стало»: слева жёлтый блок «Было», стрелка, справа зелёный блок «Стало», изменившиеся слова подсвечены; добавленная — открывается целиком.
- Статьи, изменённые за последние 14 дней, помечены «изменено» в результатах, а в самой статье — кнопка «Изменено ДД.ММ.ГГГГ · было → стало».
- В настройках — «Что изменилось в законах» (обновления за 60 дней). Esc идёт назад по слоям: «было → стало» → статья → список.
- Тесты: `src/core/changes.test.ts`, `src/importer/changelog.test.ts`, `src/ui/Changes.test.tsx` (экран один раз после смены версии, не на первом запуске, «было → стало», метки, настройки).
