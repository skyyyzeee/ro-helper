# 02: Каркас приложения

**What to build:** Проект открывается в обычном браузере и показывает пустое окно оверлея в утверждённом стиле: стекло, шапка «РО Хелпер», строка поиска с курсором. Всё нативное (горячая клавиша, окна, буфер обмена, настройки) скрыто за платформенным адаптером. В браузере и в тестах вместо Tauri работает заглушка. Автотесты запускаются одной командой. Tauri подключается позже, в задаче 06.

Визуальный стиль берётся из макета: https://claude.ai/code/artifact/edee3d00-883e-47ee-b2d4-cc469751cb76 (стиль C), описание — в спецификации, раздел «Интерфейс».

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] React + TypeScript + Vite. Одна команда запускает приложение в браузере, одна — тесты (Vitest + React Testing Library)
- [ ] Платформенный адаптер — интерфейс со всеми операциями из спецификации: горячая клавиша, показать/скрыть оверлей, положение и размер окна, «поверх всех», окно закрепления, буфер обмена, настройки, внешняя ссылка. Есть заглушка для браузера и тестов
- [ ] Ядро законов — отдельный модуль без зависимостей от интерфейса и Tauri, пока с пустым публичным интерфейсом
- [ ] Визуальные токены взяты из макета: тёмно-серое стекло, белый текст с тенью, шрифт Onest, синий и коралловый акценты, цвета бейджей категорий, радиусы
- [ ] Тест интерфейса: окно оверлея рендерится, курсор стоит в строке поиска
- [ ] `.gitignore` покрывает зависимости и сборки
