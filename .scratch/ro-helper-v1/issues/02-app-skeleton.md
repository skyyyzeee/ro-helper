# 02: Каркас приложения

**What to build:** Проект открывается в обычном браузере и показывает пустое окно оверлея в утверждённом стиле: стекло, шапка «РО Хелпер», строка поиска с курсором. Всё нативное (горячая клавиша, окна, буфер обмена, настройки) скрыто за платформенным адаптером. В браузере и в тестах вместо Tauri работает заглушка. Автотесты запускаются одной командой. Tauri подключается позже, в задаче 06.

Визуальный стиль берётся из макета: https://claude.ai/code/artifact/edee3d00-883e-47ee-b2d4-cc469751cb76 (стиль C), описание — в спецификации, раздел «Интерфейс».

**Blocked by:** None (can start immediately)

**Status:** done

- [x] React + TypeScript + Vite. Одна команда запускает приложение в браузере, одна — тесты (Vitest + React Testing Library)
- [x] Платформенный адаптер — интерфейс со всеми операциями из спецификации: горячая клавиша, показать/скрыть оверлей, положение и размер окна, «поверх всех», окно закрепления, буфер обмена, настройки, внешняя ссылка. Есть заглушка для браузера и тестов
- [x] Ядро законов — отдельный модуль без зависимостей от интерфейса и Tauri, пока с пустым публичным интерфейсом
- [x] Визуальные токены взяты из макета: тёмно-серое стекло, белый текст с тенью, шрифт Onest, синий и коралловый акценты, цвета бейджей категорий, радиусы
- [x] Тест интерфейса: окно оверлея рендерится, курсор стоит в строке поиска
- [x] `.gitignore` покрывает зависимости и сборки

## Comments

2026-09-10 — сделано:
- **Стек:** React 19, Vite 8, TypeScript 7, Vitest 5 + React Testing Library, jsdom. Шрифт Onest вшит через @fontsource, работает офлайн, кириллица есть.
- **Команды:** `npm run dev` (браузер, http://127.0.0.1:1420 — порт, который ждёт Tauri), `npm test`, `npm run typecheck`, `npm run build`.
- **Платформенный адаптер** — `PlatformAdapter` с событием `onOverlayShown`, чтобы при каждом показе оверлея курсор возвращался в поиск. Заглушки: `fake` записывает все вызовы для тестов; `browser` добавляет настоящий буфер обмена, ссылки и сохранение настроек в localStorage.
- **Граница ядра** закреплена тестом: файлы `src/core` не могут импортировать React, Tauri, `ui` или `platform`.
- **В браузере** под оверлеем рисуется условная сцена игры, чтобы стекло было видно. В Tauri фон прозрачный, и оверлей занимает всё окно.
- **Тесты:** 4 зелёных. Проверка типов и сборка чистые. Вид сверен с макетом в браузере.
- **`.gitattributes`** (`eol=lf`) убирает предупреждения о переводах строк.
