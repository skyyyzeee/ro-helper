# 12: Правила проекта хранятся трижды

**Status:** resolved

13 тем общих правил лежат копиями в `data/<server>/sources` каждого сервера. Обновил одну копию — серверы разошлись. Завести общую папку (например, `data/_shared/sources`) и брать оттуда при сборке всех пакетов.

## Answer

14 документов правил проекта (всё `rules-*`, кроме `rules-server`) теперь хранятся один раз — в `data/_shared/sources`. Импортер при сборке пакета сначала ищет снимок в `data/<server>/sources`, а если его там нет — берёт из `data/_shared/sources`; собственный снимок сервера по-прежнему побеждает общий, если понадобится переопределить документ для одного сервера. `rules-server` остался у каждого сервера свой — тексты различаются. Пакеты после переноса пересобраны байт-в-байт теми же.
