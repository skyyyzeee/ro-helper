# 14: Режим «Заработок»

**Status:** needs-triage

Отдельный режим хелпера, переключатель в шапке «Законы ⇄ Заработок».

Идеи:
1. Расписания из правил: ограбления бизнесов и банков (12:00–01:00), график Форта по дням — «до открытия 1 ч 20 мин», «Форт сегодня 16:00–18:00».
2. Таймеры и откаты: свои таймеры (поставка, работа, кейс) с уведомлением поверх игры по окончании (уведомления уже есть с 1.0.15).
3. Учёт смены: «Начать смену» → вписываешь суммы → доход в час/день/неделю, какой способ выгоднее.
4. Справочник заработка: работы, оплата, требования, где брать — данные нужно собрать.

Нужно от пользователя: на чём реально зарабатывают в РО (работы, бизнес, фракция, криминал), есть ли PayDay, где взять цифры. Начать можно с 1–3, им внешние данные не нужны.
