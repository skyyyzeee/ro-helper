# 11: Загружать законы только выбранного сервера

**Status:** resolved

## Answer

Уже сделано (b23bf20, 1.0.17+): `src/data/index.ts` грузит пакет сервера через `import()` — Vite режет каждый в свой чанк (сборка 02.11.2026: tverskoi/arbatskiy/kutuzovskiy отдельными файлами по ~5 МБ), до выбора сервера читаются только килобайты `servers.json`. С GitHub качается тоже только пакет выбранного сервера (`src/ui/laws.ts`: манифест → `packUrl(server)`), кэш — `readLaws`/`writeLaws`. Проверено 02.11.2026.

Все три пакета (~13 МБ JSON) входят в сборку и грузятся при запуске, хотя нужен один. Разделить на отдельные чанки (`import()` по серверу) — быстрее запуск и меньше памяти. С 1.0.17 пакет может приходить и с GitHub — учесть это в загрузке.
