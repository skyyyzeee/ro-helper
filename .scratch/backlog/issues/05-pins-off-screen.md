# 05: Закреплённые карточки за пределами экрана

**Status:** needs-triage

Карточка, закреплённая на втором мониторе, сохраняет свои координаты. Если монитор отключить, карточка окажется вне экрана, достать её можно только через «Настройки» → «Открепить всё».

Решение: при загрузке и при смене мониторов возвращать блоки в пределы видимых экранов (`clampTo` по текущей поверхности).
