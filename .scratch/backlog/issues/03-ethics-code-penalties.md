# 03: Кодекс этики: наказания не выделяются

**Status:** needs-triage

Арбатский и Кутузовский, Кодекс этики, ст. 36: подпункты 36.1, 36.2… и строки «Наказание: штраф в размере 5000 рублей» склеиваются в текст статьи — не красным и не отдельными пунктами.

Причина: документ разбирается форматом `law`, а правило «Наказание:» есть только в разборщике `points`. Решение: научить `law` подпунктам «36.1» и строке «Наказание:» либо разбирать этот документ как `points`.
