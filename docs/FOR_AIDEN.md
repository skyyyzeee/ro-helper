**Закреплённая карточка «замораживала» другие программы — исправлено, 2.23.2** (PR #154). Пока была
закреплена одна карточка, Chrome, Firefox, Edge, Discord и остальные программы на Chromium переставали
перерисовываться. Окно карточек растянуто на весь рабочий стол и вырезано по карточкам (`SetWindowRgn`);
Chromium (и Firefox, у него та же проверка) считает программу закрытой, если её накрывает видимое окно без
`WS_EX_TRANSPARENT` с простым вырезом, и берёт за его размер весь прямоугольник окна. Теперь окно карточек
всегда `WS_EX_TOOLWINDOW` (`pin_window::set_click_through` в `src-tauri/src/lib.rs`), такие окна эта проверка
пропускает; нативный тест рядом. **Не убирай этот флаг** и не делай других окон на весь экран без него.
Было так минимум с 2.20.

**Статистика статей для сервера ИИ — `article_stats`** (PR #153, миграция
`supabase/migrations/20261024000000_article_stats.sql`). Все статьи сервера по дням: `day`, `article`, `count`,
за последние `days` дней (по умолчанию 7, не больше 30). Те же обезличенные числа, что и у
`popular_articles`; таблица закрыта, вызывается с publishable key, который уже лежит в `.env` сервера, —
никаких секретов. Миграция запущена 24.10.2026 — уже работает; числа копятся с 24.10.

```bash
curl -X POST https://evwyrdytojwxlvgqrkar.supabase.co/rest/v1/rpc/article_stats -H "apikey: <SUPABASE_PUBLISHABLE_KEY>" -H "Content-Type: application/json" -d "{\"target\":\"tverskoi\",\"days\":30}"
```

За один ответ — до 1000 строк; дальше `limit` / `offset`. В `PRIVACY.md` уже сказано, что эти числа может
читать кто угодно, в том числе сервер ИИ. Если понадобится другой срез — напиши, сделаем ещё функцию.

**Как синхронизироваться.** Кто игрок и что ему можно — только Supabase; сервер ИИ спрашивает его токеном
игрока (ADR 0002). Данные ИИ (оценки, разборы, кэш, лимиты) остаются у тебя на сервере. Изменения в Supabase —
файлом в `supabase/migrations` в pull request, запускает skyze. Меняется таблица `roles` или `is_admin()`, которые
читает сервер ИИ, — об этом будет запись здесь.
