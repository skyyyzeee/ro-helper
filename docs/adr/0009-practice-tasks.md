# ADR 0009 — Модель заданий практики без ИИ

**Статус:** принято · **Этап:** 6А ([ROADMAP](../ROADMAP.md)) · **Дата:** 09.10.2026

## Проблема

Практика («Практика» в ИИ) была только с ИИ: вопрос и проверка ответа тратят дневной лимит, требуют сети и
сервера ИИ, а отзыв ИИ всё равно приходится сверять со статьёй. Новичку в силовой структуре нужно быстро и
много раз выучить номера статей и наказания — для этого ИИ не нужен.

## Решение

- **Задание** (`QuizQuestion`, `src/core/quiz.ts`) — вопрос, четыре варианта ответа, номер правильного и
  статья, о которой вопрос. Делается из пакета законов сервера, без ИИ и без сети.
- **Три вида**, по очереди в раунде:
  - «Какой номер?» — по названию статьи выбрать «УК ст. 65»;
  - «О чём статья?» — по номеру выбрать название;
  - «Какое наказание?» — по части статьи (с названием статьи и её пунктами) выбрать санкцию, как её пишет
    `formatPunishment`.
- **Правильный ответ — текст пакета**, остальные три — того же документа и все разные. Поэтому задание не может
  спросить то, чего нет в законах сервера, и не может подсказать чужой кодекс.
- **Раунд** — 10 заданий по выбранным документам (по умолчанию — документы организации, как у экзамена с ИИ);
  статья спрашивается один раз; сначала статьи с наказанием (то, что сотрудник встречает на службе), остальные —
  если их не хватило. Документ, где нечего спросить (нет названий и наказаний), даёт пустой раунд и говорит об этом.
- **Интерфейс** — «Практика» → «Быстрые задания» (по умолчанию) и «Экзамен с ИИ» рядом. Ответ — кнопкой или
  клавишами 1–4, после ответа — какой верный и кнопка открыть статью. Результаты нигде не хранятся.

## Альтернативы

- **Ввод ответа текстом** («напишите номер статьи»): отклонено — без ИИ нельзя честно проверить формулировку, а
  номер с вариантами проверяется точно.
- **Отдельная вкладка «Тренажёр» в боковой колонке**: отложено — «Практика» уже есть у тех, кому она нужна
  (силовые структуры, `ai.practice`); новая вкладка — изменение дизайна C, согласуется с владельцем отдельно.

## Последствия

- Практика работает без входа, без сети и без лимита ИИ.
- Если позже захочется хранить историю результатов или наборы заданий по организациям — это поля к
  `QuizQuestion` и отдельное хранилище, не новая модель.
