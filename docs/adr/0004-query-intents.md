# ADR 0004 — Словарь запросов с намерениями

**Статус:** принято · **Этап:** 2Б ([ROADMAP](../ROADMAP.md)) · **Дата:** 15.10.2026

## Проблема

Поиск ищет статью, в которой есть **каждое** слово запроса. Игрок же пишет своими словами: «что ему впаяют за
кражу», «чела приняли», «что мне положено при задержании», «сколько штраф за парковку». Слов «впаяют», «ему»,
«чела» в законах нет — поиск не находил ничего, и игроку оставалось спрашивать ИИ (лимит, сеть, ожидание).
«Штраф за превышение скорости» находил не КоАП, а статью, где просто встречаются эти слова.

## Решение

- **Намерение** (`Intent`, `src/core/model.ts`) — что спрашивает запрос: «Наказание», «Задержание», «Права и
  обязанности», «Правила сервера». У каждого:
  - слова, которыми его спрашивают, в тех формах, как их пишут игроки («впаяют», «дадут», «приняли», «положено»);
  - где ответ — виды документов (`penal-code`, `law`, `charter`, `rules`) и/или документы по id;
  - что искать, если кроме намерения ничего не написано («чела приняли» → «задержание»);
  - `punished` — ответ только статьи с наказанием.
- **Словарь** (`Dictionary`) — намерения и слова-«наполнители», которые ничего не говорят о законе («ему»,
  «чела», «сколько», «могут»). Один на все серверы: `data/intents.json`; импорт кладёт его в каждый пакет
  (`pack.dictionary`). Синонимы (`synonyms.json`, «ствол» → «огнестрельное оружие») остаются по серверам.
- **Цепочка** (`searchUnderstood`, `src/core/intent.ts`): нормализация → словарь → намерение → его документы →
  обычный поиск того, что осталось от запроса.
  - Намерение — то, чьих слов в запросе больше; при равенстве — первое в словаре.
  - Запрос по номеру или с названием документа («ук 65», «8.6») не разбирается: игрок сам сказал, где искать.
  - Короткая основа (меньше 5 букв) или основа, общая для двух намерений («права» и «правила» — обе «прав»),
    узнаётся только в написанной форме.
  - Если строгий поиск в документах намерения пуст, а слов несколько — каждое слово ищется отдельно
    (`findForSituation`), только в этих документах.
- **Намерение никогда не теряет результат.** Если в его документах ничего не нашлось — обычный поиск по запросу
  как есть, затем по запросу без наполнителей. Тогда строка «Понял как» не показывается.
- **Интерфейс.** Над результатами — «Понял как: **Наказание**» и где искали («УК, КоАП»); кнопка «Искать везде»
  отключает намерение для этого запроса (в главном окне и в быстром поиске).

## Альтернативы

- **Спрашивать ИИ, что имел в виду игрок:** отклонено — каждое нажатие клавиши в поиске стало бы обращением к
  серверу; цель этапа — как раз меньше обращений к ИИ.
- **Словарь на каждый сервер:** отложено — разговорные слова у игроков одинаковые; если понадобится, сервер может
  положить свой `intents.json` рядом с `synonyms.json`, это изменение импорта, не модели.
- **Поднять `PACK_FORMAT`:** не нужно — старое приложение читает пакет мимо нового поля, а новое без словаря ищет
  как раньше (проверено тестом).

## Последствия

- Типичные разговорные вопросы находят статью без ИИ на всех трёх серверах (набор «запрос → намерение → первая
  статья» в `src/core/intent.test.ts`).
- Словарь обновляется вместе с законами из `main`, без выпуска программы.
- Риск — намерение сужает слишком сильно; защита — запасной обычный поиск и «Искать везде». Новые слова
  добавляются в `data/intents.json` с примером в тестах.
