# УПК Тверского: сверка форума и отменённые основания

24 ноября 2026. Проверен первоисточник: https://forum.russia.online/threads/ugolovno-protsessual-nyi-kodeks.1177/ . Страница прочитана обычным in-app browser, без обхода защиты. Chrome в доступном наборе браузеров отсутствовал. Проверялся УПК целиком; остальные законы/уставы/правила этой итерацией заново по форуму НЕ сверялись.

## Подтверждение сообщения игроков

На форуме и в прежнем локальном снимке статьи81.1,81.2,81.4,81.5,82.1 уже имеют заголовок «Утратила силу», без действующего содержания. Источник ошибки — не только свежесть базы: отменённые записи могли попасть в пакет источников ИИ, а существующий реальный номер статьи мог пройти проверку существования. Удалять запись из каталога не нужно: пользователю полезно видеть факт отмены.

Исправлено в протоколе: packInScope не включает отменённые статьи в AI-поиск; sourcesBlock не передаёт отменённую запись, даже если она пришла из старого списка; checkNorm отвергает отменённую норму, включая восстановленный ответ; groundItems не принимает её как основание проверки сотрудника. Каталог/прямое чтение исходного пакета сохраняют пометку отмены. Проверка заголовка явная, не по одному отсутствию частей.

## Актуализация текста

По главам и статьям сравнены нормализованные тексты. Отличались статьи52,78,80.8,85:

-52: при задержании госслужащего указан также следователь Следственного комитета РО.
-78: уточнены реквизиты постановления и направление его копии подозреваемому/обвиняемому, прокурору при необходимости.
-80.8: добавлен свидетель в розыск.
-85: сроки7дней для следствия/4для дознания, исчисление при возвращении дела, порядок продления.

После переноса точных изменений ВЕСЬ нормализованный текст локального upk.txt совпал с прочитанным DOM первого поста:151086символов, FNV-1a n2065808990. Нормализация — последовательности пробельных символов в один пробел и trim. Это проверка целостности копирования, не криптографическое доказательство достоверности сайта. Сами тексты принадлежат Russia Online.

Форум не отобразил дату последнего редактирования. Поэтому lastEdited не выдумывался: сохранена прежняя известная дата, snapshotAt=2026-11-24. Четыре подтверждённых изменения внесены в changelog пакета с временем обнаружения/импорта, затем пакет и manifest пересобраны штатным importer. Его первое сообщение назвало изменения parser из-за неизменившегося lastEdited; это не реальная причина изменения текста, а ограничение классификации импортера. Новая запись changelog создана по diff этих четырёх статей, версия импорта2026-11-23T21:33:42.568Z (24ноября по Asia/Krasnoyarsk).
