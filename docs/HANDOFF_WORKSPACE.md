## Как собрать и восстановить

В рабочем клоне:

```powershell
git status --short
git switch codex/search-workspace
npm ci
pwsh -File scripts/build-workspace.ps1
```

`npm ci` нужен, если зависимости отсутствуют. Скрипт сам собирает frontend, подставляет `src-tauri/tauri.preview.conf.json`, запускает **cargo build --release --features tauri/custom-protocol**, затем проверяет версию и актуальность встроенных assets. Нужны Rust, Windows Build Tools, Node.js и cargo в PATH. Нативная сборка занимает примерно 3–5 минут.

Важно: один `cargo build --release` БЕЗ `tauri/custom-protocol` в этом проекте может собрать окно, открывающее dev URL `127.0.0.1:1420`, а не автономное приложение. Пользоваться подготовленным скриптом. Не менять production identifier/ключ подписи ради превью.

Клон shallow. Резервный bundle содержит нашу ветку поверх базового `697063a`; для восстановления коммитов нужен репозиторий с этим базовым коммитом. В свежем клоне upstream с доступным основанием:

```powershell
git fetch 'C:/Users/sed19/Downloads/protocol-handoff/claude_code_package/protocol-app/artifacts/workspace-preview/workspace-work.bundle' codex/search-workspace:codex/search-workspace
git switch codex/search-workspace
```

Если Git-восстановление пока недоступно, `workspace-source.zip` содержит весь код для сборки. Не продолжать в старом `protocol-app/src` по ошибке. Не выполнять автоматически старый план с fast-forward/merge из октябрьского раздела передачи поверх этой рабочей ветки.

При UI-проверке читать текущий снимок окна. Windows accessibility иногда возвращает старую структуру сразу после действия; свежий screenshot показывает реальный результат. Если пользователь сам управляет окном — не бороться за мышь. При пересборке завершать только тестовый процесс по точному пути; установленную production-копию не трогать.
