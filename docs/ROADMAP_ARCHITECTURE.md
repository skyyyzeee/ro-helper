# Аудит архитектуры к roadmap

Разбор текущего состояния Кремлёвского Ассистента (Release 2.9.1, 01.10.2026) перед развитием в единую
платформу. План этапов — в [`ROADMAP.md`](ROADMAP.md), решения, требующие согласования, — в [`adr/`](adr/).

Документ описывает то, что есть в коде сейчас. Когда код меняется, меняется и он.

## 1. Слои сейчас

```
src/core        законы: модель пакета, поиск, калькулятор, изменения. Чистый TypeScript (boundary test).
  ↑
src/protocol    ИИ-конвейер поверх core: контекст, формат ответа, проверки по законам, провайдеры. Чистый.
  ↑
src/ui          React: Overlay.tsx (главное окно), QuickSearch.tsx (Alt+S), PinSurface.tsx (карточки
                поверх игры), экраны ИИ, настройки.
src/account     аккаунты (Supabase: Discord, Telegram), синхронизация настроек, роли (RolesApi).
src/platform    всё нативное за PlatformAdapter: tauri / browser / fake.
src-tauri       окна main, pin, quick; горячие клавиши; фокус игры; вход; хранение законов.
server/         сервер ИИ (Айден): GigaChat, затем платный API; дневные лимиты.
supabase/       миграции и edge-функция входа через Telegram; выполняет владелец.
src/data        пакеты серверов (tverskoi, arbatskiy, kutuzovskiy), manifest.json, announcements.json.
```

Главное правило уже соблюдается: **законы, поиск и калькулятор детерминированы, ИИ только толкует
найденное**. ИИ видит лишь статьи, найденные поиском, под id; `protocol/validate.ts` сверяет каждую
статью, часть и цифру с пакетом; наказание считает калькулятор (`docs/SOURCE_GROUNDING.md`).

## 3. Найденные ограничения

1. **`src/ui/Overlay.tsx` — 1691 строка.** Поиск, калькулятор, закрепления, быстрый поиск, ИИ-запросы,
   недавние, избранное — всё состояние в одном компоненте. Каждая новая функция делает его больше; это
   главный кандидат превратиться в монолит. Нужно выносить состояние в хуки по областям (`useCharges`,
   `usePins`, `useQuickBridge`, …) до того, как добавлять «Дела» и команды.
2. **Сервер ИИ анонимный.** Лимиты — на компьютер и IP-адрес, входа нет. Любые права на ИИ-функции сейчас
   держатся только на интерфейсе, то есть не держатся.
3. **«История» только локальная и по серверам.** На другом ПК разборов нет; снимка базы у разбора нет —
   видно лишь, что статья изменилась, при повторной проверке.
4. **Три разных «ничего не найдено»**: главный поиск (`Overlay.tsx`), меню документов (`DocumentsMenu.tsx`),
   быстрый поиск (`QuickSearch.tsx`, с подсказкой Tab → ИИ). Ни один не говорит, что искали и где.
5. **Две версии пакета с похожим смыслом**: `version` (время последней правки закона) и `built` (время
   сборки пакета). Человеку ни одна не понятна; для снимка «Дела» нужны ещё отпечатки статей.
6. **Организация ничем не подтверждена**: игрок выбирает её сам. Закрывать функции по организации нельзя,
   пока нет подтверждения членства.
7. **Экраны ИИ — пять вкладок** («Разбор ситуации», «Составить документ», «Требования адвоката»,
   «Разбор задержания», «Тренажёр») плюс «История». Логика — зона Айдена, он её перестраивает.

## 6. Как Server Pack повлияет на архитектуру

Пакет уже главный носитель серверной специфики, core от сервера не зависит. Развитие — **добавлять поля в
тот же `ServerPack`**, а не заводить второй формат:

```
ServerPack
├── format, built, version        есть
├── server                        есть
├── documents (laws, charters, rules)   есть
├── calculator                    есть
├── synonyms                      есть → развить в словарь с намерениями (этап 2)
├── organizations                 есть → развить в профили организаций (этап 1)
├── label                         новое: версия для людей, «2026.10.1» (этап 1)
└── changes                       есть
```

Чего в пакете не будет: политики ИИ и права по ролям. Политика ИИ — на сервере Айдена; права по ролям —
в базе (RLS) и на сервере ИИ. В пакете только то, что одинаково для всех игроков сервера и обновляется
вместе с законами.

Любое изменение формы пакета, которое старое приложение прочтёт неверно, поднимает `PACK_FORMAT`: старые
копии оставят свои законы до обновления. Новые необязательные поля `PACK_FORMAT` не поднимают.

## 7. Что сделать раньше остального

1. Профиль организации и права — модель, на которую опираются показ функций, практика по организациям и
   будущая проверка на сервере ИИ.
2. Вынести состояние из `Overlay.tsx` в хуки — до «Дел» и команд, иначе они лягут в тот же файл.
3. Понятная версия пакета и отпечатки статей — до «Дел» (снимок) и кэша ответов.
